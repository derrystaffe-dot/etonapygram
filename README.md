# etonapygram

Мод Telegram для iOS. Собирается из исходников [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) в GitHub Actions, на выходе получается IPA.

## Что умеет

Все функции настраиваются в **Настройки → etonapygram**.

**Режим-призрак** (работает, только пока включён главный переключатель):
- скрывать «в сети»: аккаунт всегда отправляет статус «не в сети»;
- скрывать «печатает», «записывает видео / голосовое», «отправляет видео / фото / файл»;
- скрывать прочтение: собеседник не видит, что ты прочитал сообщения (в личке, группах, каналах, ветках форумов и комментариях);
- скрывать «прослушано / просмотрено» у голосовых и кружков;
- анонимный просмотр историй;
- исключения: люди из списка всегда видят твой настоящий статус.

**Сообщения:**
- сохранять удалённые: сообщение, удалённое собеседником, остаётся в чате, рядом со временем появляется 🗑;
- сохранять историю изменений: у изменённого сообщения в меню (долгое нажатие) есть пункт «История изменений» со всеми прошлыми версиями текста.

**Профиль:**
- показывать ID пользователя, группы или канала (нажатие копирует);
- примерная дата регистрации аккаунта (точность — несколько месяцев);
- спойлер на своём номере телефона.

## Как собрать

1. Получи свои `api_id` и `api_hash` на https://my.telegram.org/apps.
2. В репозитории открой **Settings → Secrets and variables → Actions** и добавь секреты `TG_API_ID` и `TG_API_HASH`.
   Без них сборка возьмёт `api_id` из конфигурации самого Telegram и выдаст предупреждение.
3. **Actions → Build IPA → Run workflow.** Сборка запускается и сама при каждом пуше.
4. Через 1–3 часа (первая сборка самая долгая, следующие быстрее за счёт кэша) IPA появится:
   - в разделе **Artifacts** запуска;
   - в **Releases**, если запускал вручную с галочкой `release`.

## Как установить

IPA подписан самоподписанным сертификатом, поэтому его нужно переподписать при установке:
- **Sideloadly** или **AltStore** — с бесплатным Apple ID (приложение работает 7 дней, потом переустановить);
- **ESign / Scarlet / Feather** — со своим сертификатом;
- **TrollStore** — без переподписи, если устройство его поддерживает.

Перед установкой удали официальный Telegram или смени bundle ID в Sideloadly, иначе приложения будут конфликтовать.

## Как это устроено

```
TELEGRAM_COMMIT            коммит Telegram-iOS, на котором собирается мод
mod/                       новые файлы, копируются поверх исходников Telegram
  submodules/EtonaSettings     хранилище настроек (только Foundation)
  submodules/EtonaSettingsUI   экраны настроек и истории изменений
  submodules/TelegramCore/Sources/Etona  логика режима-призрака и сохранения сообщений
patches/etonapygram.patch  правки существующих файлов Telegram
scripts/apply.sh           накладывает мод на исходники Telegram
scripts/make-patch.sh      пересобирает patches/ из изменённых исходников
.github/workflows/build.yml  сборка в GitHub Actions (раннер xcode-27)
```

### Обновление на новую версию Telegram

1. Поменяй коммит в `TELEGRAM_COMMIT`.
2. Склонируй Telegram-iOS на этом коммите и запусти `scripts/apply.sh <путь>`.
3. Если патч не наложился, поправь конфликтующие места руками прямо в исходниках Telegram и запусти `scripts/make-patch.sh <путь>`.
4. Проверь в `versions.json` Telegram, какая версия Xcode нужна, и при необходимости поменяй раннер и путь к Xcode в `.github/workflows/build.yml`.
